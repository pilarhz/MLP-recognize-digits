# Digit recognizer
## Description
Application uses multilayer perceptron(MLP) to recognize digits between 0 and 9. After being trained by X epochs on MNIST dataset, app lets you draw your own digit. Then based on what you drew it tries to tell you what digit it thinks it is by assigning a probability (in %) to each digit.
## MNIST dataset
This project uses the **[MNIST database](http://yann.lecun.com/exdb/mnist/)** of handwritten digits, created by Yann LeCun, Corinna Cortes and Christopher J.C. Burges.

The dataset is **not included** in this repository.
